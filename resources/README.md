# resources/

Small, fixed reference files with **no participant-level data**. They are kept under version control so that
identifiers and figure layouts match the published results exactly.

| File | Used by | Generated by | Required |
|---|---|---|---|
| `clinical_layout.rds` | `R/network_layout.R` (scripts 12, 14, 15) | `make_clinical_layout()` in `R/network_layout.R`, applied to the clinical-only MariNET network | **yes** |
| `uniprot_to_hgnc_mapping_full.rds` | 09 | Ensembl BioMart query (`uniprotswissprot` → `hgnc_symbol`), plus the manual fix `O15197 = EPHB6` | **yes** (09 stops without it) |
| `gene_map_v100_full.rds` | 03, 04 | Ensembl BioMart query (`ensembl_gene_id` → `hgnc_symbol`) | recommended |
| `exclude_genes_ENSEMBL_v100.rds` | 01 | MT-/RPL/RPS/HB* genes from the same Ensembl query | recommended |

If the last two files are missing, scripts 01 and 03 query the **current** Ensembl release and save the result here.
Gene symbols, and therefore the DEG list, can then differ slightly from the published run.
